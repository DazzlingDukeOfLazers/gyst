# Gyst icon search map

Icons should answer a question faster than the nearby headline. Search for the
concrete object or action first; avoid broad category terms such as “platform,”
“innovation,” or “digital transformation.”

## Selection rules

1. Prefer a literal noun over an abstract metaphor.
2. Use one icon per primary idea and reuse it when the same object returns.
3. Recolor and frame icons consistently; do not pretend unrelated icon sets are
   one illustration.
4. Inspect the rendered shape. Search metadata can be wrong or visually
   misleading—the first “change history” result was rejected for this reason.
5. Bundle assets locally and retain creator, source, and license information.
6. Keep the timeline’s cost curve and activity lanes as data visualizations,
   where labels and values carry more meaning than an icon.
